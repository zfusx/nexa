# 实施任务与验收清单 v0.2

## 建议实施顺序

| 任务                   | 主责             | 依赖                         | 完成定义                                                 |
| ---------------------- | ---------------- | ---------------------------- | -------------------------------------------------------- |
| T01 范围与入口确认     | 产品/核心        | D02-D04                      | 首发路径、免费/收费边界、真实模块签认                    |
| T02 设计系统与页面稿   | 设计             | 本交付；D01 正式品牌可后替换 | 八路由设计、三题/30 题结果、断点及状态稿，H/C/S 编号对应 |
| T03 静态壳与内容工程   | 前端             | 当前源码 + T02               | 可访问主站、组件、无 JS 降级、测试和 CI                  |
| T04 核心契约与测试环境 | 核心/前端/安全   | D06-D07                      | schema、权限、幂等、脱敏成功/错误样例                    |
| T05 真实计算与解释接入 | 前端/核心        | T03-T04                      | 不把样例当真报告，覆盖任务生命周期与数据不足             |
| T06 账户与数据管理     | 核心/前端/隐私   | D07-D09                      | 跨账户隔离、保存/删除、会话失效验收                      |
| T07 权益与支付         | 商业/核心/前端   | D03、D09、T06                | 金额服务端可信、回调验签/去重、结果未知与对账            |
| T08 内容与研究发布审阅 | 产品/研究/法务   | D04-D05、D08                 | 能力、白皮书、政策、真实联系客服入口签认                 |
| T09 上线演练           | QA/运维/各负责人 | T05-T08                      | 下表生产项目通过，灰度/告警/回滚演练完成                 |

T02、T03 与 T04 可由团队并行安排；这不是本次自动启动的外部任务。正式品牌未定不必阻塞组件结构工作，数据与交易契约未定则不能上线对应功能。

| A06 | 结果与重置           | 明确示例标记；重置回第一题；CTA 不进入未确认开发环境  | 浏览器/构建检查              |

| A10 | 320/390/768/桌面     | 无横向溢出、遮挡，卡片按断点排列                      | 浏览器                       |

实际已运行项目与结果见 `WORKLOG.md`；本表是操作规范，不是预先填写的全通过报告。

## 上线签认

产品负责人确认范围与权益；设计确认页面及状态；核心/前端确认契约与环境；QA 给出测试报告；研究确认公开主张；隐私/法务确认适用政策；运维确认监控、回滚与当班人。价格、数据政策、权限或生产证据缺失时，不以演示验收代替正式签认。
