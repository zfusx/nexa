# 页面与用户流程规格 v0.2

状态：已实现基线 + 明确标注的生产版建议。与旧策略冲突时，本文件的“已实现”部分为准。

## 产品目标

主站把好奇心转化为理解与自愿体验。主要对象是对关系、职业和不确定处境有困惑的中文用户。成功不是让用户相信一个确定预言，而是让他理解产品、免费获得一个可读视角，并知道下一步将去哪里。

研究与依据：[竞品录屏](../research/竞品录屏漏斗分析.md)、[代表网站](../research/代表性网站研究.md)、[Nebula 补充](../research/Nebula双站补充分析.md)。研究结论不是 Nexa 转化率实测；广告 Hook 到站效果仍需上线后评估。

| ID   | 模块         | 传达内容/行为                                              | 交付参考                       |
| ---- | ------------ | ---------------------------------------------------------- | ------------------------------ |

## 微体验：确定的状态与规则

| 状态    | 问题与选项                                             | 触发后的行为          | 返回/清理                   |
| ------- | ------------------------------------------------------ | --------------------- | --------------------------- |
| S0 主题 | 一段关系 / 一次选择 / 一件悬着的事                     | 记录主题，进入 S1     | 改选主题清空后续帮助与感受  |
| S1 帮助 | 看清局面 / 判断时机 / 找到下一步                       | 记录帮助，进入 S2     | 可返回 S0；改选帮助清空感受 |
| S2 感受 | 我怕自己看错了 / 我不知道还要等多久 / 我担心做了会后悔 | 记录感受，立即显示 S3 | 可返回 S1                   |
| S3 结果 | 标题、观察、张力、行动、追问句                         | CTA 暂留在方法页      | 重新体验清空所有答案，回 S0 |

每步只需要一次选择，未回答不能通过不存在的“下一步”跳过。焦点随步骤移动到题目；首次加载不抢焦点。进度为 1/3、2/3、3/3，结果页不显示题目进度。

三项各三个选项，共 27 个可达组合。结果是本地规则文案：主题决定标题/观察，帮助决定张力/行动，感受进入追问句。它不是 LLM 调用、命理计算或心理诊断。不得加“正在解析命盘”的假等待来增强仪式感。

刷新清空答案；没有会话恢复、出生数据收集、上报、登录、收藏、支付或后端缓存。浏览器无 JavaScript 时显示说明并提供方法阅读入口，不暗示体验仍可提交。

## 独立 30 题引流体验：当前实现

`/quiz` 是供广告或深链直接进入的独立演示页。30 道原创陈述题按“辨认事实、守住边界、开始验证、理解节奏、真实连接”五个维度均衡分布；每题提供“不太像我 / 有一点像 / 很像现在的我”三个选择。用户可逐题返回修改，完成后立即看到五项分布、当前较自然的方式、值得补足的方向和一条具体行动建议。

评分在浏览器内由固定规则完成，反向题只用于减少同意偏差；结果是当下自我观察，不是固定人格标签、心理诊断、命理计算或现实预测。页面刷新会清空答案，当前没有埋点、UTM 持久化、账户、邮件、生日、支付或服务端请求。正式产品 CTA 暂时安全指向站内方法页。

## 产品化后的用户路径（建议，未实现）

品牌或广告入口 → 三题快速体验或 30 题独立测试 → 免费解释结果 → 用户自愿进入正式产品 → 根据所选服务说明资料用途 → 必要的资料确认与计算 → 可读结果及依据 → 自愿登录保存/购买明确权益。

账户验证放在哪一步由核心架构和业务方确认；若计算前确需登录，应提前说明。不要把未注册的页面体验伪装成免费完整命盘，也不要在输入资料后才首次披露付费门槛。

真实结果至少应支持：输入摘要、观察、依据、局限、可行动问题、版本/生成时间、修改输入入口。缺失出生时刻不能凭空补齐；有关传统领域的字段必须沿用核心团队已经确认的命名契约。
