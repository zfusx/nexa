# Nexa 方法与数学框架白皮书

让复杂有章可循，让理解经得起追问。

传统知识 · 数学建模 · 概率与稳定性 · AI 解释

Nexa 研究的不是如何把术语堆得更多，而是如何把传统体系中的对象、条件、关系和变化写成可复算、可追溯、可质疑的计算过程。

本稿公开模型类别、数学对象、验证逻辑与证据边界；不公开规则表、参数、权重、阈值、提示词和实现细节。文中公式用于说明研究框架，不表示所有模块均已上线，也不构成现实预测准确率的证明。

## 01｜研究对象：从术语集合到可审计模型

八字与易学不是一张关键词清单。一个判断通常同时依赖历法边界、位置、季节、十神、藏干、合冲刑害、格局条件、时间尺度与具体问题。若这些对象没有各自的数据类型和计算顺序，同一份资料很容易因为叙述顺序不同而得到互相冲突的答案。

### 三层模型，而不是一个神秘总分

Nexa 将方法拆成三个彼此约束的层次。事实层处理出生信息、历法、节气和已经发生的起卦过程；结构层处理传统关系、必要条件、组成状态与时间路径；解释层把计算依据、不确定性和现实问题组织成自然语言。

```text
input -> facts F -> structure Z -> evidence E -> explanation A
                 version V ------^       uncertainty U ------^
```

这里的关键不是箭头画得多，而是每一层都有明确责任。历法模块不能偷偷写结论；语言模型不能自行补算干支；界面重试不能重新生成一次已经完成的随机过程。每份结果应绑定规则版本、参数版本、历法版本与生成记录，使历史输出可以重算或解释差异。

### 形式化问题

设原始输入为 x，事实变换为 F(x; v_c)，结构计算为 Z(F; v_r, theta)，解释器为 A(E, U, q; v_m)。其中 v_c、v_r、v_m 分别表示历法、规则和语言模型版本，theta 表示内部参数，q 表示用户问题。

```text
E, U = Z(F(x; v_c); v_r, theta)
answer = A(E, U, q; v_m)
trace = (v_c, v_r, theta_version, v_m, evidence_ids)
```

公众不需要看到 theta 的数值，却应知道结论属于哪个版本、依据来自哪里、哪些条件没有满足。商业机密可以留在内部，过程责任不能因此消失。

### 数学能保证什么

数学可以约束输入是否合法、概率是否归一、必要条件是否被绕过、同一版本能否复算、微小误差是否导致大幅翻转。它不能单独证明传统命理对现实事件具有预测效力。工程正确、传统一致、解释质量和现实有效性，是四类不同证据。

> 专业不是把答案写得更确定，而是让对象、假设、版本与未知都能被看见。

## 02｜组成几何：五行不是五个独立分数

在年运与月运的模型设计中，五行被表示为一个相对组成。若用 x=(x1,x2,x3,x4,x5) 表示木、火、土、金、水的非负份额，闭合后的状态满足所有分量之和为一。

```text
x_i > 0,  i = 1,...,5
sum_i x_i = 1
x belongs to a 4-dimensional simplex with 5 parts
```

这类数据与普通坐标不同：一项占比上升，必然改变其他项的相对占比。直接对百分比做加减、平均或欧氏距离，容易把“整体规模”和“内部比例”混为一谈。Nexa 因此借鉴成分数据分析与 Aitchison 几何，把比较转移到对数比空间。

### 中心对数比

令 g(x) 为五个分量的几何平均，中心对数比变换把每一项写成它相对整体几何中心的对数比例。

```text
g(x) = (product_i x_i)^(1/5)
clr_i(x) = ln(x_i / g(x))
d_A(x,y) = || clr(x) - clr(y) ||_2
```

d_A 是公开层面的 Aitchison 距离表达。它比较的是两个组成的相对结构，而不是把五个百分数当成互相独立的长度。实际系统还必须处理零分量、数值精度和闭合不变量；具体替换规则与阈值属于内部版本化参数。

### 多来源融合

本命、时间周期和季节语境可以看成多个组成来源 x^(r)。若 w_r 为非负且和为一的来源权重，Aitchison 中心可以用加权几何平均再闭合来表示。

```text
center_A = C( product_r (x^(r))^(w_r) )
w_r >= 0,  sum_r w_r = 1
C(z) = z / sum_i z_i
```

这一定义具有尺度不变性：把某个来源的所有原始质量同时放大，不应仅因此改变其内部组成。公开公式说明数学对象和不变量，但不公开 Nexa 对不同来源采用的具体 w_r。

### 浓度、位移与吉凶必须分开

组成集中度可以由熵类指标描述，当前状态相对背景的变化可以由 d_A 描述；它们都不是天然的吉凶分数。集中说明分布更偏向少数分量，位移说明相对背景变化更大。解释方向仍需由明确的传统关系与问题语境提供。

```text
H(x) = - sum_i x_i ln(x_i)
concentration = 1 - H(x) / ln(5)
shift = d_A(x_current, x_background)
```

> 先选择正确的数学空间，再讨论距离和变化；否则精确的小数也可能只是精确地表达了错误对象。

## 03｜条件系统与关系图：先成立，再评分

传统格局、十神与地支关系包含大量条件语句。两个术语同时出现，只能说明它们共存，不代表某个格局已经成立。Nexa 将类别判定与程度估计分开：必要条件负责门控，连续函数只描述通过门控后的强弱、清晰度或稳定性。

### 必要条件是布尔门

设 P_k(z) 是第 k 个结构的必要条件集合，g_k(z; theta) 是连续程度函数。公开层可将最终内部量写成：

```text
P_k(z) in {0,1}
score_k(z) = P_k(z) * g_k(z; theta)
0 <= g_k(z; theta) <= 1
```

当 P_k(z)=0 时，再高的连续分也不能把缺失的必要条件“补成成立”。不同古籍或流派对 P_k 的定义可能不同，因此规则档案需要记录 school、source、version 和适用范围，而不是把分歧藏进一个总分。

### 有向关系不能随意相消

五行生克与部分地支关系具有方向。可把关系写成有向图 G=(V,E)，以矩阵 A 表示从 i 到 j 的作用强度。一般情况下 A_ij 不等于 A_ji；“我生”和“生我”、“我克”和“克我”不能压成同一个无方向标签。

```text
G = (V, E_generate union E_control)
A_ij != A_ji  in general
flow_ij(z) = z_i * A_ij * z_j
```

flow_ij 保留从 i 到 j 的有序作用，不把矩阵压缩成会丢失反对称部分的单一二次型。生产模型还要保留关系类型、参与对象、位置、是否成局以及冲突解析顺序。方向相反的信号可以同时存在：它们会提高结构活跃程度，却未必在倾向上互相抵消为零。

### 集合规则与路径规则

六合、六冲、刑、害、三合等关系不都属于同一种数学对象。有些可表示为配对集合，有些要求方向，有些必须满足完整成员集合，还有些依赖作用路径。统一接口可以共享“参与节点、关系类型、来源版本”，但不能为了代码简洁而抹平语义差异。

```text
relation = (participants, direction, condition, source, version)
active(relation,z) = condition(z) and path_exists(z)
```

这种表示让测试能够穷举触发与非触发样例，也能解释“为什么同一个字出现了，却没有形成相同判断”。

### 从职业到关系：保持方向与现实约束

职业模型把岗位任务、组织环境和现实能力作为约束，不只匹配行业名称；合盘模型分别计算 A 对 B 与 B 对 A 的影响，不假设结果对称。无论数学关系多复杂，学历、技能、边界、沟通与现实相处都不能被传统映射取代。

> 门控防止高分越过必要条件；有向图防止不同作用被错误合并。二者共同守住规则的语义。

## 04｜时间路径：年、月、日是多尺度状态序列

传统时间分析至少包含年、节气月与日三个尺度。首先要解决的不是“这段时间好不好”，而是每个时刻属于哪个周期、交界如何处理、较长周期如何覆盖较短周期。

### 半开区间与真实覆盖

每个时间区间采用左闭右开约定：包含当前节气起点，不包含下一节气起点，使相邻区间既不重叠也不留空。若较长周期在月中切换，其权重由与当前区间的真实重叠时长决定。

```text
I_t = [s_t, s_(t+1))
w_tj = duration(I_t intersect J_j) / duration(I_t)
sum_j w_tj = 1
```

这比“月中一律算旧运”或“一律算新运”更稳定，也使时间边界可以被单元测试。时区、节气来源、历法版本和交接规则必须进入事实层，不能由 AI 根据文字猜测。

### 状态不是一串互不相干的月分数

设 x_t 是第 t 个周期的五行组成，c_t=clr(x_t)。相邻位移 v_t 描述组成空间中的变化，a_t 表示变化幅度，turn_t 描述方向是否发生显著转折。

```text
c_t = clr(x_t)
v_t = c_t - c_(t-1)
a_t = ||v_t||_2
turn_t = 1 - cosine(v_(t-1), v_t)
```

年度平均、波动、最大位移和转折点应分别输出。一个平均值可能看似平稳，却掩盖月内或年内的明显转向。转折阈值和排序逻辑属于待校准参数；没有超过阈值时，应返回“没有显著转折”，而不是为了填满页面制造事件。

### 强度与方向是两个轴

同一时期可能同时存在支持与牵制信号。若只做净相减，两个都很强的结构可能被压成接近零。更合理的公开表示是保留活动强度 m_t 与方向向量 d_t，再由解释层说明“变化很多”与“整体偏向哪里”。

```text
m_t = sum_r |effect_r(t)|
d_t = sum_r effect_r(t) * direction_r
```

m_t 高而 d_t 接近零，表示相反作用并存，不表示什么都没有发生。内部评分也不能直接改名为事件概率；若要输出概率，必须另外完成标注、校准和外部验证。

### 日历别名与伪相关

流日研究容易与星期、季节、节假日和经济周期产生别名。60 日干支周期与 7 日星期周期的最小公倍数是 420 日，因此验证不能只取一个短窗口。研究设计应覆盖多个组合周期，按用户与时间切分，并用保持日历结构的置换或对照检验排除简单周期解释。

> 时间模型的专业性，首先体现在边界无重无漏，其次才是如何解释路径、波动和转折。

## 05｜不确定性：模糊边界、鲁棒性与校准

真实输入会有误差，传统规则会有分歧，分类边界也不天然锋利。专业系统不应把这些不确定性藏起来，而应测量一个结论对输入、参数和规则版本有多敏感。

### 模糊逻辑处理连续过渡

“偏弱、适中、偏强”便于表达，但硬阈值会让非常接近的输入落到完全不同的类别。可用隶属函数 mu_k(x) 表示输入同时接近多个状态的程度，再对不同状态下的候选结果做连续融合。

```text
0 <= mu_k(x) <= 1
sum_k mu_k(x) = 1
score(c|x) = sum_k mu_k(x) * score(c|state_k)
```

隶属函数只负责平滑边界，不负责创造新的传统规则。函数形状、中心与陡峭度需要版本化，也需要根据真实样本重新校准。

### 扰动测试回答“结果稳不稳”

设 f(x) 输出候选排序，在允许误差范围内从分布 D_eta 采样扰动 epsilon_b，重复 B 次。候选 c 的 Top-K 稳定率可以写成：

```text
epsilon_b ~ D_eta
S_c = (1/B) * sum_b 1[c in TopK(f(x + epsilon_b))]
```

S_c 衡量算法对小扰动的敏感程度，不是职业成功率、事件发生率或命理真实性。稳定率较低时，产品应展示并列候选、缺失信息与敏感来源，而不是强化第一名。

### 资料不完整时向中性收缩

令 q 表示本次计算依据的完整程度，s_raw 是内部原始分，s_0 是中性参考点。一个保守的展示策略是：

```text
s_display = q * s_raw + (1-q) * s_0
0 <= q <= 1
```

q 低表示依据不足，不表示某个职业或关系本身“不适合”。在资料严重缺失时，系统可以停止精确排序，只说明目前能够判断的范围。

### 如果发布概率，就必须检查校准

当系统未来对事先定义的二元事件发布概率 p_i，并获得真实标签 y_i 时，可使用 Brier score 与 Log Loss；对于罕见事件，还应报告基准发生率、precision、recall、PR-AUC，并给出校准曲线。

```text
Brier = (1/N) * sum_i (p_i - y_i)^2
LogLoss = -(1/N) * sum_i [y_i ln(p_i) + (1-y_i) ln(1-p_i)]
```

在没有独立留出数据前，内部强度、启发式可信度与扰动稳定率都不得写成概率。准确率也不能替代校准：对罕见事件永远回答“不发生”，可能看似准确，却没有实际区分力。

> 不确定性不是产品的缺陷说明；把它量化、解释并转化为更谨慎的行动，是模型责任的一部分。

## 06｜OCQM-6：六步观察耦合随机过程

一次起卦包含内部爻值生成、硬币画面、用户观察、六爻确定性变换与后续解释。OCQM-6 将这些环节分开，研究的问题是：在六个离散步骤中，若允许历史与观察信息改变后续条件分布，怎样保持概率合法、基线可退化、过程可审计。

### 状态空间与概率

每一爻的内部状态属于 I={6,7,8,9}。量子概率表示使用密度矩阵 rho_t；合法状态要求 rho_t 半正定且迹为一。若 P_i 是对应状态的投影算子，Born 规则给出下一爻取值概率。

```text
rho_t >= 0,  Tr(rho_t) = 1
p_t(i) = Tr(rho_t P_i)
p_t(i) >= 0,  sum_i p_t(i) = 1
```

这里的密度矩阵是一种组织概率、状态与上下文的数学语言。它不构成人的意识导致宏观量子坍缩的物理证据，也不要求量子硬件。

### 观察之后，下一步怎样改变

第 t 步的结果、选择性观察状态和经过过滤的上下文共同形成历史 h_t。条件转移核 T_t(i,j|h_t) 决定下一步分布。六爻联合概率不是六个页面效果的拼接，而是条件概率的乘积。

```text
p_(t+1)(j) = sum_i p_t(i) * T_t(i,j | h_t)
P(y_1,...,y_6) = product_t P(y_t | y_1,...,y_(t-1), h_(t-1))
```

任何 T_t 都必须逐行非负且归一。启用平稳校正时，指定传统基线 pi 还需满足 pi T_t=pi。观察耦合强度归零时，模型必须精确退化为所选传统独立基线；否则无法知道新增机制究竟改变了什么。

### 生成、显示与解释不能倒置

内部爻值应先生成，三枚硬币只是该状态的条件显示。界面刷新、网络超时或重试不得让同一爻重新抽取；互卦、错卦、综卦等必须由六个已生成爻确定性计算，不得回写当轮生成状态。

```text
generate y_t -> persist event -> render coins -> observe -> update h_t
retry(request_id) -> return persisted event, not a new draw
```

### 如何比较模型

OCQM-6 应与传统独立基线、经典 Markov 或其他更简单的序列模型比较。比较对象包括联合分布、序列依赖、对数似然、校准和消融结果。若简单模型达到相同解释力，应优先采用简单模型。即使序列模型更好地描述实验数据，也不能直接推出卦象解读对现实问题有效。

> “量子启发”的专业含义是明确状态、测量和条件更新；它不是把神秘感包装成物理证明。

## 07｜可解释 AI 与证据治理

AI 擅长把复杂结构转成自然语言，也可能把不确定的信号写得过度肯定。Nexa 因此不让语言模型直接面对未经约束的原始术语，而是先提供结构化证据包，再要求回答区分计算事实、传统解释、模型综合与现实建议。

### 证据包是解释接口

证据包 E 至少包含事实、规则触发、未满足条件、相互冲突的信号、适用版本和不确定性 U。语言模型可以调整表达和组织顺序，但不能修改 E 中的计算事实，也不能补造未出现的事件。

```text
evidence packet E = (facts, rules, conflicts, scope, versions)
uncertainty U = (missing, sensitivity, disagreement, calibration)
answer A = LLM(E, U, user_question, safety_policy)
```

一个可追问的答案，应能回到 evidence_ids：这个观察依据什么？哪个条件没有成立？换一种规则版本会怎样？现实经历不符合时应该相信什么？

### AI 质量需要单独测量

计算测试通过，不代表解释就可靠。解释层至少需要检查依据覆盖、事实一致、矛盾率、不确定性表达、安全边界与可理解性。自动评测可以发现明显错误，但仍需人工盲审与真实用户研究。

```text
groundedness = supported_claims / checkable_claims
omission_rate = omitted_required_items / required_items
contradiction_rate = contradictory_pairs / checked_pairs
```

这些指标衡量文本是否忠实于提供的依据，不衡量命理的现实预测效度。高风险问题涉及医疗、法律、财务、家暴、人身安全或心理危机时，应优先回到现实证据与专业支持，而不是继续强化命理结论。

### 四级证据阶梯

- L1 计算正确性：历法、映射、条件、概率与数值不变量是否按版本执行。
- L2 来源可追溯性：传统关系、流派差异与规则来源是否清楚。
- L3 解释一致性：AI 是否忠实于证据、标明模型综合与不确定性。
- L4 现实有效性：冻结后的模型能否在未参与调参的人群和未来时间段提供可复核增益。

现有资料支持方法设计、数学对象和验证方案的说明；本次整理没有获得可独立复核的生产实现清单、真实样本规模、完整评测结果或第三方验证报告。因此，v0.2 不发布准确率、成功率或“优于其他产品”的结论。

### 公开、保密与可复核

公众可以看到问题定义、数学类别、不变量、评估设计、版本和结果限制；核心规则表、参数、权重、阈值、提示词、实现路径与私密数据保留在内部。每次公开结果应同时说明任务、样本、对照、时间切分、失败案例和适用范围，而不是只展示最好看的数字。
