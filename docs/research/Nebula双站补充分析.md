# Nebula 双站与交互漏斗补充分析

研究日期：2026-09-14。研究对象为 [Nebula Natal Chart](https://nebula-natal-chart.com/) 与 [AskNebula](https://www.asknebula.com/)。本次使用公开页面和虚构资料进行浏览器体验，停在注册、聊天或付款之前；营销数据只作为页面主张记录，不作真实性背书。

## 结论摘要

两个网站承担不同任务：

- `nebula-natal-chart.com` 是广告承接与订阅转化微站，以“定制星盘”为名进入 18 步个性化问卷。
- `asknebula.com` 是品牌主站、内容媒体和真人顾问市场，以“3 分钟免费”降低第一次咨询门槛，再按分钟销售真人服务。

真正值得 Nexa 学习的不是长问卷和折扣，而是 AskNebula 已经形成的信任基础设施：顾问档案、价格、咨询次数、内容审校流程、事实与解释边界、安全中心、危机资源和举报入口。

## 两个站分别在做什么

| 维度       | Nebula Natal Chart                                 | AskNebula                                                |
| ---------- | -------------------------------------------------- | -------------------------------------------------------- |
| 核心角色   | 广告/活动落地页                                    | 品牌、内容和顾问交易平台                                 |
| 首屏承诺   | 用占星引导生活，完成测验获得定制计划               | 每次灵性咨询都更接近“grounded wisdom”                    |
| 主入口     | Start → 18 步问卷                                  | 选顾问或领取新客 3 分钟                                  |
| 主要商品   | 个性化占星订阅                                     | 真人顾问按分钟聊天                                       |
| 个性化机制 | 性别、生日及后续问题                               | 性别、问题主题、阅读方式、生日 → 匹配顾问                |
| 信任机制   | 媒体 Logo、用户规模、准确率、评价、顾问数量        | 顾问卡片、价格、Trustpilot、审核标准、内容规范、安全中心 |
| 主要风险   | 注册前投入过长、同意与追踪绑定、准确率缺少方法说明 | 免费优惠压过实际续费价格、弹窗打断、真人服务可能形成依赖 |

## 实际体验路径

### A. Nebula Natal Chart

1. 首页用“Navigate life's challenges”与“Hyper-personalized Astrology”建立方向感。
2. 同页展示四个结果类型：一对一指导、占星解读、自我理解、关系模式。
3. 用媒体 Logo、`20 million` 用户、`93% accuracy`、`4.7/5` 和 `300+ advisors` 集中完成社会证明。
4. 点击 Start 后明确显示 `1/18`，副文案写明测验用于加入并个性化 Nebula subscription。
5. 第一题选择性别；必须另外勾选隐私、条款、Cookie 与包含 Meta Pixel 的追踪同意，才能继续。
6. 第二题请求完整出生日期，默认值为 1990-01-01。

本次会话在出生日期页面出现 React hydration 错误（控制台错误码 418/423）。点击 Continue 时进度从 `2/18` 增至 `4/18`，问题却仍停留在生日页。这个现象只代表本次浏览器会话，不能推断所有用户都必然遇到，但它说明长漏斗的每一步都增加了技术与转化风险。

### B. AskNebula 顾问匹配

1. 首屏顶部固定展示 `3 Minutes FREE + 80% OFF For New Customers`。
2. Hero 不先讲占星技术，而是把产品描述为在不确定时提供清晰、洞察与真实连接的灵性指导空间。
3. 点击 Choose a psychic 后进入短匹配：性别 → 问题主题 → 阅读方式 → 出生日期。
4. 选择“关系”和“Astrology & Horoscope”后，系统显示 `Saving your reading preferences`，通过 42%、83% 等进度强化“正在计算”的感受。
5. 结果展示五位顾问，并给出评分、评论数、咨询次数、平台年限、专业领域和 `free 3 minutes`。
6. 匹配完成后立刻出现领取免费 3 分钟的弹窗；关闭后仍可查看顾问列表，但开始聊天会进入后续注册或计费，因此本次没有继续。

主站公开顾问价格约为 `$2.99–$4.99/min`，并在四步流程中说明：先注册、选顾问、开始聊天、添加付款信息，只在开始咨询时收费。具体价格和优惠可能变化，正式借鉴前需要再次核验。

### C. 新客简单注册页

顶部优惠跳转到 `/flow/lp/simple-registration`。页面强调：

- 第一次咨询有 3 分钟免费。
- 不需要先提供银行卡。
- 先做短问卷，再选择匹配顾问。

但第一步“点击 Male 或 Female 即同意条款与隐私政策”，选择后又出现 Cookie Policy 与 Meta Pixel 追踪说明。页面在选择前后显示的公司主体/地址也出现了 `Spiritual Nebula Limited（Cyprus）` 与 `Yolo Brothers Inc.（Nevada）` 的变化。本报告只记录界面一致性问题，不作法律关系判断。

## 值得学习的部分

### 1. 具体展示服务，而不是只讲神秘感

顾问卡片包含真人形象、擅长领域、评分、评论、咨询次数、从业平台年限和价格。用户知道自己将与谁交谈、花多少钱、为什么可能适合。

Nexa 对应做法：未来把“AI 回答”也做成可理解的结果卡，显示使用了哪些输入、采用哪个方法层、主要依据、仍然不确定的地方以及可继续追问的问题。

### 2. 把信任做成信息架构

AskNebula 页脚不是只有 Privacy 和 Terms，还提供：

- 顾问选择与模拟审核流程。
- 顾问独立执业者身份说明。
- 内容如何写作、检查和发布。
- Trust & Safety Center、危机资源、社区规则与安全举报。
- 作者与灵性审核者页面。

这说明高敏感度服务需要一整套公开治理页面，而不是一段免责声明。

### 3. 公开区分信念、事实与解释

[内容发布规范](https://www.asknebula.com/how-we-write-check-publish-our-content) 明确把占星、塔罗和能量实践称为解释性体系，不声称其提供可测量证明；天文事件和历史日期按事实处理，灵性含义按解释处理。它还说明 AI 只辅助资料组织、提纲和一致性检查，选题与最终判断由人类编辑和顾问负责。

这与 Nexa 白皮书的表达边界高度一致：数学工具可以提升结构、稳定性与可解释性，但不能被包装成“物理学已经证明命理”。

### 4. 安全规范足够具体

[Trust & Safety Center](https://www.asknebula.com/trust-safety-center) 覆盖数据、访问控制、漏洞管理、伦理指导、社区规范、危机支持和举报。[伦理指导](https://www.asknebula.com/trust-safety-center/ethical-guidance) 明确禁止恐惧营销、过度紧迫感、诅咒、不可逆后果与迫使用户继续参与。

Nexa 可以进一步建立中文情境的安全中心：医疗、心理、法律、财务、暴力、自伤、依赖性重复占卜以及未成年人保护应分别说明，而不是只在页脚放一句“仅供娱乐”。

## 不建议照搬的部分

### 1. 18 步投入后才出现价值

长问卷能制造投入感，也提高故障、退出和不信任概率。Nexa 当前“三题 → 立即得到一个视角”的方向更好；真实命理服务需要生日等资料时，应在用户理解价值与用途之后再请求。

### 2. 把条款、性别选择与广告追踪绑在同一动作

同意应能被理解和分别选择。尤其是精确生日、出生地点、私密关系问题等敏感资料，不应因为点击一个选项就默认进入广告追踪链路。

### 3. 用“准确率”代替方法与证据

`93% accuracy rated by real users` 更像满意度营销，不等于技术准确率、预测效度或可重复评测。Nexa 不应使用没有样本、定义、评测方法和时间范围的准确率数字。

### 4. 免费入口与实际价格距离过远

“3 分钟免费”很具体，也有效，但用户还需要在进入聊天前看到免费结束后的每分钟价格、余额消耗方式、结束会话方法和是否存在自动续费。

### 5. 把“正在分析”当作个性化证据

42%、83% 的过场能够增加期待，却不能证明后台进行了多复杂的计算。Nexa 的进度反馈应该对应真实任务，并允许用户查看输入、方法与完成状态。

## 对 Nexa 的落地建议

### 现在保留

- 保留首页三步微体验，不要求注册，不上传选择。
- 保留“计算正确、传统一致、现实有效性必须分开说明”的 FAQ。
- 保留不制造恐惧、不下宿命判决、每个结论都能追问的品牌原则。

### 下一版可以增加

1. 一张更接近正式产品的“可追问答案卡”，同时展示依据、不确定性和下一步。
2. 正式产品 CTA 旁直接说明是否免费、何时注册、何时付费及是否续费。
3. 独立的“内容与 AI 如何审核”页面，并公布更新周期和责任人角色。
4. 中文 Trust & Safety Center，包括危机资源、举报、隐私、依赖预防和高风险主题处理。
5. 有真实评测后再发布数字，并同时给出指标定义、样本和限制。

### 暂时不要增加

- 不因为竞品存在就添加虚构用户数、准确率、媒体 Logo 或顾问数量。
- 不把三题体验扩成长测试。
- 不在尚无真人服务时模仿顾问头像与在线状态。
- 不用虚假扫描、倒计时或没有真实后台任务的百分比过场。
