# 竞品录屏漏斗分析

研究日期：2026-09-14
样本：`othersite/` 中两段 Nebula 婚姻解读录屏与 11 张截图

## 研究方法

- 使用 FFmpeg 以每秒 1 帧抽取 675 张画面。
- 使用场景阈值 `0.16` 捕捉 119 个明显视觉变化点。
- 使用简体中文与英文 OCR 提取关键文案，再人工对照联系表。
- 时间点为相对视频起始时间，允许约 ±1 秒误差。
- 本报告描述样本中的实际界面，不代表对其计算有效性或商业条款作独立认证。

## 漏斗总览

```text
社交广告或深链
→ 婚姻悬念承诺
→ 33 题心理/生活偏好测试
→ 出生日期
→ 手掌拍摄与分阶段“分析”
→ 邮箱或支付账户保存
→ 稀缺性结论与模糊结果
→ €1 / 7 天试用
→ €49.99/月自动续订
→ €7.99–€14.99 单次加购
→ 手机号营销同意
→ 强制式 App 迁移
→ 应用内 8 天内容解锁
```

## 样本中的 Hook 层级

1. **结果型 Hook**：会和谁结婚、什么时候结婚。
2. **身份型 Hook**：只有少数人拥有这样的婚姻线。
3. **过程型 Hook**：33 题、出生日期、手掌扫描共同制造“为我而算”。
4. **缺口型 Hook**：名字首字母、日期和正文只露出标题或模糊轮廓。
5. **价格型 Hook**：€1 明显大于 €49.99/月续订说明。
6. **连续型 Hook**：8 天计划、每日章节和下一章节预告。

## Nexa 应学习什么

- 一个落地页只处理一个明确问题，不从抽象“了解命运”开始。
- 使用 5–8 个高信息量问题形成渐进投入，并明确还需多久。
- 用真实计算步骤的可视化建立等待价值，而不是虚假进度。
- 结果页先给出一个完整洞察，再展示深入内容与付费选项。
- 把“为什么得到这个结论”做成核心交互，而不是只展示神秘结果。
- 允许用户在 Web 直接查看购买内容；App 是便利选项，不是领取结果的障碍。

## Nexa 不应采用什么

- 没有依据的百分位和稀缺性统计。
- 虚假倒计时或并不存在的限时折扣。
- 完成漫长流程后仍不给任何实际结果。
- 弱化自动续订金额、日期、取消方法或退款规则。
- 付费后立即连续加购，再强迫下载 App。
- 将服务通知和营销授权捆绑。
- 用确定性的婚姻、健康、财务或人身安全预言制造依赖。

## 建议的 Nexa 替代漏斗

```text
一个真实困惑
→ 选择问题方向
→ 5 个轻量问题
→ 展示正在使用哪些输入与方法
→ 免费交付一条完整洞察与一条现实建议
→ 可展开查看依据
→ 注册以保存和继续追问
→ 清晰展示付费得到什么、价格和取消方式
```
