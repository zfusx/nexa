# Nexa SVG 图标系统与复用清单

版本：v0.5；日期：2026-09-14。对象：UI/UX、前端、品牌与产品团队。

## 结论

测试站已经形成三层图标语言：星芒与轨道负责品牌气质，导航图标负责产品结构，线性操作图标负责明确动作。主站沿用这套“气质与操作分层”的原则，并仅本地化了产品当前公开使用的 Nexa 图标、星芒与页面背景；其余功能图标仍以语义和造型规则为参考。

本演示新增 `src/components/NexaIcon.astro`，提供十个重新绘制的 SVG 符号，并在 `/design-system#foundation` 展示桌面与手机用法。它们只由基础几何路径组成，不依赖远程图片、图标字体或第三方请求。

## 页面结构补充

- 月运：免费摘要之后依次展示锁定能量图、关键日历、月度正文、三项行动计划与四类解读。
- 年运：免费摘要之后依次展示三件要事、年度轨迹、格局总览、四个关键事件、天赋锚点、六个人生领域和十二节气时间轴。
- 详情：今日事件、月运与疗愈内容使用最大 640px、高度接近全屏的底部弹层，紫色渐变背景；标题栏固定，正文滚动。
- 六爻结果：长文末尾统一放置喜欢、不喜欢、朗读、分享和重新解读；更多菜单把删除标为 `#FF5A6A`，与一般操作分开。
- 法律长文：正文约 600px、14px/24px，适合长阅读；当前页面同时出现两个 H1，正式实现应改为一个页面 H1 加文章标题层级。

## 演示站可直接使用的十个符号

| 名称 | 组件值     | 主用途               | 使用限制                 |
| ---- | ---------- | -------------------- | ------------------------ |
| 星芒 | `spark`    | 品牌强调、标题前缀   | 只作装饰时隐藏辅助技术   |
| 轨道 | `orbit`    | 结构化计算、方法说明 | 不表示真实计算状态       |
| 罗盘 | `compass`  | 方向、引导、选择     | 不用于定位权限           |
| 图表 | `chart`    | 分布、趋势、报告     | 同时提供文字和数值       |
| 盾牌 | `shield`   | 隐私、边界           | 不能替代真实安全说明     |
| 文档 | `document` | 白皮书、报告、条款   | 与下载动作分开           |
| 刷新 | `refresh`  | 重新测试、重新生成   | 说明是否覆盖旧结果或收费 |
| 分享 | `share`    | 分享报告或链接       | 纯图标按钮提供可读名称   |
| 朗读 | `voice`    | 语音播放             | 播放后切换为暂停状态     |
| 箭头 | `arrow`    | 继续、站内跳转       | 外链另加新窗口提示       |

## 程序与设计规则

- 基准画布 `24 × 24`，默认线宽 `1.65px`，圆角端点，颜色继承 `currentColor`。
- 常规操作尺寸 20–24px；仅图标按钮的可点击区域不小于 44×44px。
- 装饰 SVG 使用 `aria-hidden="true"`；没有可见文字的图标按钮必须提供 `aria-label`。
- 选中状态至少同时使用颜色和文字/形状变化，不能只靠发光或紫色。
- SVG 保持内联或由同域静态资源提供，禁止从测试站 URL 热链。
- 测试站使用的 Lucide 图标可以作为语义参考；正式项目若引入 Lucide 包，应保留其 [ISC 许可证与版权声明](https://lucide.dev/license)。

Figma 中建立 `Icon / 24` 组件集，至少包含默认、悬停、聚焦、禁用和选中状态；每个实例标注名称与用途。品牌装饰与功能操作分组，避免把高光星芒用作删除、支付或隐私等严肃动作。

前端以 `NexaIcon.astro` 为当前原型入口。未来迁移到 React/Vue 时，保留 `name`、`size`、`label` 和 `currentColor` 契约，并做 24px、20px 与高对比主题的视觉回归。
