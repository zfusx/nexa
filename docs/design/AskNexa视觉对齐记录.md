## 第二轮色差复核（2026-09-14）

本轮以用户提供的并排截图为视觉基准，再分别读取测试站 `/bazi-home`、`/bazi-reading` 与演示站 `/whitepaper` 的 computed style。两边的最底层并没有明显偏差：测试站 body 为 `#0B0620`，功能页为 `#0E0620` / `#110630`；演示站 body 为 `#0B0620`。观感差异主要来自上层合成，不是单纯“背景紫色取错”。

| 观察项     | 测试站实测                                                                         | 当前演示站                                                     | 结论与后续调整                                                                    |
| ---------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 首屏色温   | 空间照片以蓝黑、冷灰与低饱和紫为主                                                 | 大面积 `#352356` 径向光斑                                      | 演示站更暖、更灰，也更像平面渐变；应减少该光斑面积与绿/红分量，转向冷蓝紫         |
| 页面与主卡 | 页面 `#110630`，主卡高频 `#21124B`                                                 | 辅助卡 `#171032`，当前版本卡 `#211849`                         | `#211849` 比 `#21124B` 更偏灰；主卡应恢复冷紫，不要所有层级都共用 `#171032`       |
| 渐变层     | 年运卡 `#391F80 → #110630 → #44269A`；锁定遮罩至 `#170552`；标号 `#4E2AB1`         | 白皮书首屏主要只有 `#352356 → transparent`                     | 测试站的“深度”来自多段冷紫而非单个光斑；营销/产品页可重用多段层次，长文页应更克制 |
| 表面边界   | 常用 `rgba(169,143,232,.14–.55)`，全局细线 `rgba(201,177,255,.18)`                 | 主要使用 `rgba(201,177,255,.18)`，当前版本卡直接使用 `#C8B8EF` | 演示站部分边框偏白、偏硬；应用紫色透明度创建远近层级                              |
| 正文层级   | 白 `#FFFFFF`，主次文 `#C9C2E4`，辅助文 `#A19BBB`，链接 `#8871FF`                   | 主文 `#F8F3FF`，通用次文 `#B6A9D6`                             | 主站标题略暖，正文又比测试站主次文更暗；应补充中间文字级，不要只有“白/暗紫灰”两档 |
| 语义强调   | 时间/命书使用 `#E9C87E` / `#EFC469`，产品操作使用 `#8871FF`，特定主 CTA 才使用紫红 | 紫红 CTA 与淡紫标签占主导                                      | 可在版本、研究里程碑或时间信息中少量引入金色，但不能把命理专属语义滥用到全站      |
| 图像纹理   | 年运页由实景式宇宙图像贡献高光、颗粒与黑场                                         | 白皮书用 CSS 径向渐变                                          | 这是页面类型差异，不应直接拷贝照片；主站可用原创星点、噪点或几何轨道提供微纹理    |

页面类型需分开处理：截图左侧是窄栏产品报告，右侧是桌面端长文白皮书。宽度、标题字号、固定顶栏与底部导航不应强行做成一样；应统一的是色温、表面层级、边框透明度、文字阶梯和原创图像纹理的质感。

## v0.5 实施结果

- 将 body 星夜底、产品页底、主卡、辅助表面和三档文字分成独立令牌，不再用一个灰紫色替代多层蓝紫。
- 白皮书移除 `#352356` 大面积暖灰光斑，改为 Dev 年运顶部星体图与 `#110630` 遮罩；当前版本卡改为 `#391F80 → #21124B → #110630 → #44269A` 冷紫层次。
- 全站顶栏、页脚与 favicon 使用产品站 App mark；通用 eyebrow 使用 Dev 星芒 SVG。
- 首页右侧改用产品站橙蓝几何冥想插画，保留一张 Nexa 解释卡；独立测试页使用同图的低透明背景版本。
- 资产保存在 `public/brand/`，不热链产品站；页面不复制 Dev 中的账户资料、命盘或解读文案。

## 适配决定

性别/关系卡片为 10px 圆角，选中描边为亮蓝至紫色；兴趣多选使用蓝紫填充，来源单选则使用紫红填充与右侧圆形选中标记。账号入口的 Google 按钮是白底黑字，邮箱入口是透明描边胶囊。不同功能存在视觉变体，不能把所有选中态都统一成一个渐变。

测试站补充：今日能量卡用绿、红、橙、金、青五色柱状图，柱体向深紫底部渐隐；主按钮更鲜明并有玫红光晕。演示问卷沿用五色图表的视觉语言，柱高对应原问卷 0–100 分，数据含义仍为自我观察倾向。匹配页采用插画场景加底部玻璃面板；设置页采用分组列表卡；订阅页采用蓝紫外描边与单选控件；六爻入口采用紫色渐变背景和问题气泡。这些功能布局作为后续产品化参考，本轮主站不新增对应业务。

深入功能页后确认：月/年报告采用“免费摘要 + 锁定卡片 + 时间轨迹”，长结果把喜欢、朗读、分享、重新生成等动作统一放在正文末尾。测试站同时使用自有星芒/轨道/导航资产与 Lucide 线性操作图标。主站原有十个重新绘制的通用 SVG 继续保留；v0.5 另按用户指定复用产品站的品牌标志、星芒与顶部图像，并全部本地化。具体资产族、页面结构、语义、授权边界与无障碍规则见 [SVG 图标系统与复用清单](SVG图标系统与复用清单.md)。

原有米白/宋体编辑式视觉改为全站深色无衬线语言。首页保留中文品牌句、内容顺序和双栏布局，用同源橙蓝插画取代原 CSS 星球；测试页统一按钮、卡片、进度与结果，手机隐藏重复侧栏，题目切换将完整卡片滚动到固定导航下方。白皮书网页采用同源年运星体图和暗色阅读遮罩，两份已交付 PDF 保留原排版和内容。
