# 设计系统与组件规格 v0.5

这是设计团队的重建基线，不是最终品牌 VI。网页参考：[设计系统](https://main.zfis.net/design-system)。实现令牌以 `src/styles/global.css` 为准；组件行为以产品流程规格为准；SVG 命名、复用、授权与无障碍规则见 [SVG 图标系统与复用清单](SVG图标系统与复用清单.md)。

## 视觉方向

按用户指定的 asknexa.me / dev.asknexa.me 统一视觉：星夜底 `#0B0620`，产品页底 `#110630`，功能主卡 `#21124B`，辅助表面 `#171032`；搭配纯白/蓝紫文字阶梯、紫红渐变按钮及无衬线字体。首页、引流页与白皮书使用产品站同源品牌标志、橙蓝几何插画和年运星体图，长文通过遮罩、行宽与行距保持可读。实际采样和来源见 [AskNexa视觉对齐记录](AskNexa视觉对齐记录.md)。

演示站现使用产品站 App mark PNG；产品站首页的 Nexa 字标本质为 Inter 文字，未发现独立矢量字标。设计团队仍应补交正式矢量 Logo、深浅版本、最小尺寸、安全区与使用许可。

## 排版与响应式

- 标题与正文：本站托管 Inter 4.1，中文使用 PingFang SC / Hiragino Sans GB / Microsoft YaHei / Noto Sans CJK SC。字体及 OFL 授权文件随交付包提供；无需第三方字体请求。
- 正文通常 16-17px，长文行距约 1.9；大标题使用 clamp，勿将桌面固定字号直接复制到手机。
- 间距基础建议 4/8/12/16/24/32/48/64/80/112px；不是已经导出的 Figma 变量库。
- 桌面首页双栏；≤920px Hero、体验、FAQ 改单栏，三卡模块改两栏；≤620px 卡片和结果信息改单栏。
- 白皮书独立在 900px 切单栏、540px 调整手机排版；目录由侧栏改正文上方列表。
- 独立测试 ≤850px 隐藏重复说明侧栏，≤600px 题目约 23px、选项至少 52px 高；切题保持完整卡片位于固定导航下方。
- 必交画板：390px 手机、768px 平板、1440px 桌面；补查 320px、200% 缩放、长中文标题、无自定义字体。
- 尊重减少动画偏好；动画不能阻碍阅读。原型轨道是装饰，不承载唯一信息。

| ID  | 组件             | 当前实现/代码位置                   | 设计稿需覆盖                                       |
| --- | ---------------- | ----------------------------------- | -------------------------------------------------- |
| C01 | 全局导航/页脚    | `BaseLayout.astro`                  | 桌面、手机、键盘焦点；未来抽屉另立需求             |
| C02 | 主/次/暗底按钮   | `.button*`                          | 默认、悬停、按压、focus-visible；未来禁用/提交状态 |

| C06 | 结果卡           | 同上                                | 标题、观察、张力、行动、追问、性质标记、重置       |

点击态和焦点态必须分开。触控目标建议至少 44×44px；可操作项使用 button/a，不能只给 div 加点击。当前题目变更后焦点落在新标题，重置后回第一题；结果按键盘顺序进入 CTA 与重置。

## 生产结果页与交易页需要补画的内容

结果页：输入待确认、生成中、完成、部分数据不足、失败可重试、会话过期、旧版本结果、用户主动删除。每个状态要说明用户现在能做什么；样例截图不能替代业务规则。

订阅/订单：权益比较、价格与币种/周期、是否自动续费、确认购买、支付处理中、成功、失败、结果未知、取消与退款入口。实际价格/周期/试用条款未确认前，用“字段说明”作内部布局稿，不向访客展示虚构价格或有效倒计时。

## 设计文件交付要求

建议 Figma 文件页：00 阅读说明、01 基础令牌、02 组件与 variants、03 主站桌面、04 主站手机、05 微体验与结果、06 服务状态、07 白皮书、08 标注与变更记录。

每个关键页面给出：画板尺寸、栅格/间距、文本来源、交互触发、跳转目的地、状态切换、可访问性标注、资产导出规则。组件和页面沿用 H/C/S 编号，方便设计与程序对照验收。后续如正式制作 Figma，另行创建并审核；本交付不声称已有 Figma 资产。

正式验收采用代码实机与设计稿对照；操作系统字体回退导致的合理差异与真正溢出要分开记录。详情见 [验收清单](../handoff/验收与实施任务清单.md)。

参考标准（2026-09-14 核对）：[W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[W3C 增强目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)。44px 是本项目的触控设计建议，也对应增强目标尺寸要求；不要将其误称为所有场景的 AA 最低门槛。
